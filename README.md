# Text-Sentiment-Analysis-using-RNN-LSTM( Python, TensorFlow, Keras, NLTK, NumPy, Matplotlib)
Built an RNN with LSTM layers to classify sentiment (positive/negative/neutral) from movie reviews and social media  posts, effectively capturing long-term text dependencies. 
Applied tokenization, stopword removal, sequence padding, and Word Embeddings (Word2Vec/GloVe) for dense vector  representation of input text.
Designed LSTM architecture with dropout layers trained using Adam optimizer and cross-entropy loss; visualized training metrics using Matplotlib.
